# Пересчёт рецепта на число порций

## Зачем
Приготовить блюдо ровно на нужное число порций (например, 4) и сразу видеть, сколько каких продуктов взять.

## Цели
- На странице рецепта выбирается размер порции и число порций; ингредиенты пересчитываются.
- Размер порции берётся из сетов, где встречается рецепт: «В1 Каша с добавкой — 50 г». По умолчанию — первый сет.
- Граммы порции можно поправить вручную (это же поле — для рецептов, которых нет ни в одном сете).

## Не цели
- Файлы в Obsidian не меняются; выбор порций нигде не сохраняется.
- Список покупок не меняется.

## Подходы
1. **Порция из сетов, с выбором (выбран).** Всё берётся из уже существующих данных; ничего не нужно дописывать.
2. Своя строка «Порция: 50 гр» в рецепте — лишняя работа в каждом файле, может разойтись с сетами.
3. Порция = весь рецепт — не связана с весом в сетах.

## Как работает
- Порций во всём рецепте = «Вес готового блюда» / вес порции. Вариант сета с «половиной порции» (`fraction`) даёт порцию `yieldGrams × fraction`.
- Множитель = число порций × вес порции / вес готового блюда.
- Счётчик сначала стоит на числе порций во всём рецепте (округлённом), чтобы количества совпадали с файлом.
- Округление (мой выбор): г и мл — до целых, остальное (шт, ложки) — до 0,5. Граммы в пометке «(100 гр)» тоже пересчитываются. Ингредиенты без количества не меняются.
- Раздел «Ингредиенты» в тексте рецепта заменяется пересчитанным списком; шаги приготовления остаются.
- Нет «Веса готового блюда»: выбирать граммы не из чего — счётчик умножает весь рецепт, с предупреждением.

## Оставлено исполнителю
Вёрстка в стиле существующих классов (`card`, `btn-*`, `chip`).
